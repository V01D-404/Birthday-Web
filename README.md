# Birthday Rose — Чамд, сэтгэлээсээ.

## Вэбийг нээх

ZIP-ээ задлаад `index.html` файлыг Chrome, Edge, Firefox эсвэл Safari дээр нээнэ.
Суулгах зүйлгүй. Интернэтгүй ч ажиллана. Фонт, цэцгийн зураг, хөдөлгөөн нь HTML дотроо багтсан.

## Өөрийн нэр, захиагаа оруулах

1. `edit.html` файлыг нээнэ.
2. Хүлээн авах хүний нэр, өөрийн нэр болон захиагаа оруулна. Нэр заавал биш.
3. **Урьдчилан харах** товчоор захиагаа шалгана.
4. **Вэбсайтаа татах** товчоор өөрийн үгтэй `index.html` файлыг татаж авна.
5. Татагдсан файлаа нээгээд үзээрэй. Энэ ганц файл өөрөө бүрэн ажиллана.

Эх хувилбарт ерөнхий төрсөн өдрийн мэндчилгээ оруулсан. Өөрийн үгээр сольж болно.
Засварлагчийн өөрчлөлт автоматаар хадгалагдахгүй: цонхоо хаахаас өмнө бэлэн файлаа татаарай.

## Цэцгээ дэлбээлүүлэх

- **Цэцгээ дэлбээлүүл** товчийг 5.4 орчим секунд дарж барина. Дутуу тавихад цэцэг аажмаар буцаад хумигдана.
- **Нэг дараад нээх** товчийг дарахад 7.6 орчим секундэд өөрөө дэлбээлнэ.
- Сарнай нээгдсэний дараа **«Хамгийн сайхан нь чинийх байг.»** гэсэн үг түр гарч, төрсөн өдрийн мэндчилгээ рүү зөөлөн шилжинэ.
- Мэндчилгээнээс **Чамд бичсэн захиа** товчоор захиагаа уншина.
- Толгой хэсгийн дууны товчоор намуухан төгөлдөр хуурын өнгөтэй аялгууг хүсвэл асаана.
- **Дахин үзэх** товчоор эхлэл рүү буцна.

Гарын товч: **Enter** — нээх; **Space** — дарж барих; **Escape** — захианаас буцах;
**Ctrl + Shift + E** — захиа засах. `index.html#edit` хаяг мөн засварлагчийг нээнэ.

## Шинэ хувилбар

- Бүдэг ягаан туяатай бараан дэвсгэр, даруухан гэрэл, сааралдуу ягаан үсэг, Монгол үсэгтэй Noto фонт.
- 49 гэрэл зургийн кадрыг хольж, гадна дэлбээ нь голоосоо түрүүлж зөөлөн нээгдэх хөдөлгөөн.
- Аажмаар хурдасч, төгсгөлдөө саарах дэлбээлэлт; үл ялиг амьсгалах, хөвөх хөдөлгөөн, зөөлөн нисэх цөөн дэлбээ.
- Дэлбээлэлт → хүслийн үг → үсэг бүрээрээ тодрох мэндчилгээ гэсэн дараалал.
- Дугтуй нээгдэж, захианы мөрүүд болон гарын үсэг тайван гарч ирэх хөдөлгөөн.
- Утас, таблет, компьютер болон намхан дэлгэцэд зориулсан тусдаа байрлал.
- Үйлдлийн системийн хөдөлгөөн багасгах тохиргоог дагана.

Энэ нь эх сарнайн гэрэл зургуудаас бүтсэн хөдөлгөөн; 3D модель биш.
Захиаг зөвхөн өөрийн HTML файлд оруулна. Сервер, аналитик, алсын фонт эсвэл нэмэлт сан ашиглахгүй.

## Байршуулах

`index.html`, `edit.html`, `vercel.json` файлуудыг static hosting дээр байршуулж болно.
Зөвхөн бэлэн мэндчилгээгээ байршуулах бол засварлагчаас татсан `index.html` файл хангалттай.

## Шалгалт

HTML бүтэц, JavaScript syntax, 49 зургийн decoding, цэцэг нээх/цуцлах, хүслийн түр саатал,
мэндчилгээ, захиа унших, буцах, дахин үзэх болон Монгол тексттэй засварлагчийн логикийг локал runtime дээр шалгасан.
Canvas дээр гарсан сарнайн эхлэл, дэлбээлэх үе, төгсгөлийн зургийг мөн шалгасан.
Browser-ийн дэлгэцийн харагдах байдлын шалгалт энэ орчинд боломжгүй байсан.
